# Macorva (Radiant AI)

URL: https://www.macorva.com/products/performance-management

## Features (WebSearch)
- **AI-generated initial draft of performance review** — references sources within data (transparency claim)
- **Aggregates feedback, surveys, manager notes** — into single review-ready package
- **AI risk analysis on final drafts** — flags biased language, unsupported statements for manager review
- **Personalized learning plans**
- **Real-time feedback** loop
- **No-training-data policy** — inputs deleted after submission

## Trust pattern
Two strong signals: (1) "references sources within the data" — citation-style — and (2) "flags potentially biased language or unsupported statements for manager review" — second-pass critique loop.

## Anti-patterns
**AI-generated initial drafts of full performance reviews** is the riskiest pattern in the set. Even with "manager edits", anchoring effect is huge. The transparency-by-citation mitigates but doesn't eliminate.
