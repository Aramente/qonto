# Cooleaf (ITA Group)

URL: https://www.cooleaf.com/

## Features (from defuddle)
- **Real-time recognition** — peer + manager, anywhere
- **Milestone celebrations** — birthdays, anniversaries
- **Targeted engagement surveys**
- **Manager dashboards & programming analytics**
- **Training opportunities + challenges**

## Trust pattern
Generic recognition platform — light AI claims, mostly automation around triggers (anniversary, milestone).

## Anti-patterns
**Automated milestone recognition** is borderline — if HR auto-posts "Happy 5 years!" without the manager doing it, it dilutes meaning. Not an augment failure but an authenticity failure.
