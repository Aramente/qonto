# Zavvy AI (now Deel Engage)

URL: https://www.zavvy.io/ai (404, see WebSearch)

## Features
- **AI-created growth plans** — combine concrete courses from training library with feedback results
- **AI-created career frameworks** — generate competency frameworks from role data
- **9-box, spider charts, skills matrices, timelines** — analytic visualizations
- **Continuous feedback + check-ins**
- **Linked across career frameworks → 360 → growth plans → comp review**

## Trust pattern
Growth plan is built FROM real feedback + matched to real courses in library — not generic LLM advice. Editable.

## Anti-patterns
**9-box placement** if AI-assigned would be a rating system in disguise. The classic 9-box is "performance vs potential" — AI placing people in it = auto-categorization. Must be human-positioned.
