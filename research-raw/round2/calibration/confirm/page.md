## Philosophy
"Replace politics with data." ONA (Organizational Network Analysis) — passive peer-validated collaboration data — is the foundation of every calibration discussion. Replaces manager memory with behavioral evidence.

## Primitives
- **ONA Evidence Base**: data-backed employee profiles built passively over the review cycle (cross-functional reach, influence signals, contribution patterns).
- **AI-Synthesized Profiles**: GPT-4 summaries combining ONA data, review history, manager notes. Pre-loads managers before calibration so a typical 2–3 week cycle compresses into a single 2–4 hour session.
- **AI Prioritization / Auto-Triage**: surfaces "15–20% of employees whose ratings warrant calibration" — the rest pass through.
- **Rating distribution view** + **rating movement** with ONA evidence shown side-by-side as the move happens.

## Bias surfacing — STRONGEST IN MARKET
Real-time flags for three named failure modes during calibration:
- **Recency bias** — overweighting recent months.
- **Affinity bias** — rating similar people higher.
- **Visibility bias** — favoring in-office / vocal contributors.

Each flag includes the objective ONA evidence that triggered it, so the conversation pivots back to data rather than rebutting the manager personally.

## Comments / Audit
- In-platform calibration session comments.
- **Every calibration outcome logs rationale + supporting evidence** → HR can show employees transparent reasoning instead of opaque committee decisions.

## Confirm's critique of traditional 9-box (anti-patterns)
- Manager bias in potential assessment (proximity/similarity, not capability).
- Classification without action.
- Static placements never revisited.
- Confusing current performance with future potential.
- Recency bias dominates without full-year framing.
- Skipping aspiration conversations.
- Annual-only calibration.
- Treating box placements as permanent labels.

## When NOT to use 9-box (per Confirm)
- Teams < 10 people.
- Thin performance data.
- Decisions already made, grid is theater.
- Non-transparent career cultures.

## Deployment
1–2 weeks from contract to first session (vs Workday 3–9 months, Lattice 4–8 weeks).
