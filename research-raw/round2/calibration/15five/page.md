# 15Five — Calibration Session UX

Sources:
- https://success.15five.com/hc/en-us/articles/4404620505371-How-to-run-a-calibration-session-in-15Five
- https://success.15five.com/hc/en-us/articles/360057179491-Analyze-Review-Results-Talent-Matrix

## Two synchronized surfaces on every calibration session
1. **Talent Matrix (9-box grid)** — visual; drag-and-drop to recalibrate.
2. **Calibration Table** — row-based detail; column management, AI summaries, filters.

## Talent Matrix — drag-and-drop
- Drag participant avatar from one box to another → changes their received answer (rating) in real time.
- Click avatar → text responses preview.
- Click name → drawer with custom attributes, past results, full review access.
- **Filter icon in each box's upper-left** filters the Calibration Table to only those participants.
- Labels for each box are **renameable** to match company talent philosophy.

## Calibration Table
- **Manage Columns drawer**: show/hide + reorder; preference saved per session.
- Optional columns: additional manager rating, last cycle rating, group membership, hire date, location, custom people attributes.
- **AI Review Summaries** auto-generated from self / manager / peer / upward / additional-manager reviews; refresh on resubmit.
- **Change answer in-table**: hover cell → click "..." → select new answer. Cell turns **yellow**, shows original (strikethrough) + calibrated value.
- **Participant Flags**: checkbox → Actions → Flag / Remove Flag.
- **Remove from session** via Actions dropdown.

## Filters
- People & Groups (hierarchy / group / individual).
- Attribute-based: department, location, level, salary band, custom attributes.
- **Demographic attributes** = HR-admin-only. Calibration contributors see custom attributes only.

## Activity Feed (real-time + async)
- All changes auto-log at the bottom of the page.
- Contributors **@mention** admins / collaborators / contributors for discussion.
- **Dialogue bubble icon on each change** → threaded comments on the specific move.
- Auto-save: leave and return, edits intact.

## Multi-session sync
- Participant in multiple sessions → **number icon on avatar** showing session count.
- Changes propagate live across all sessions the person appears in.

## Visibility / permissions
- Contributors see custom attributes, not demographics.
- Participants (employees) see no calibration details — only managers see original-vs-updated in the review summary.
- Managers can **edit their original comments to align with calibrated scores before sharing** with the employee.

## Lock / sign-off
- Admin locks the session before the calibrations milestone.
- Once locked, calibrated answers flow into the manager review.
- Employees never see the adjustment trail.
