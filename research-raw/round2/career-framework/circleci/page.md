# CircleCI — Engineering Competency Matrix

Source: https://circleci.com/blog/why-we-re-designed-our-engineering-career-paths-at-circleci/
Spreadsheet: https://docs.google.com/spreadsheets/d/131XZCEb8LoXqy79WWrhCX4sBnGhCM1nAIz4feFZJsEo/

## Competency areas (6)
1. Technical skills (20%)
2. Quality & Testing
3. Debugging & Observability
4. Understanding Code
5. Feedback / Communication / Collaboration (20%)
6. Leadership (17% for junior, more at senior)

## Levels (6 IC track)
- E1 Associate Engineer
- E2 Engineer
- E3 Senior Engineer
- E4 Staff Engineer
- E5 Senior Staff Engineer
- E6 Principal Engineer

## Writing style
- Active language: "does" not "can do"
- Growth = expanding impact: task -> epic -> team -> multi-team -> org
- Skills demonstrated with increasing frequency over time

## Path structure
- Separate IC and management matrices (manager one being built)
- Explicit principle: "We don't assume all engineers should aspire to becoming managers"
- Mobility: transition paths between matrices planned
