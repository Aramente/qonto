# Progression.fyi — public career frameworks aggregator

Source: https://www.progression.fyi/ — 75 frameworks across engineering, product, design, data, ops.

## Sample frameworks captured

### Rent The Runway — Engineering Ladder
- Dimensions: Technical Skill / Get Stuff Done / Impact / Communication & Leadership (4 pillars)
- Format: spreadsheet, numbered levels, dual IC + manager tracks
- URL: https://docs.google.com/spreadsheets/u/1/d/1k4sO6pyCl_YYnf0PAXSBcX776rNcTjSOqDxZ5SDty-4/edit

### CircleCI — Engineering Competency Matrix
- 6 competency areas, 6 levels (E1 Associate -> E6 Principal)
- Matrix format, separate IC vs manager matrices being developed
- URL: https://docs.google.com/spreadsheets/d/131XZCEb8LoXqy79WWrhCX4sBnGhCM1nAIz4feFZJsEo/

### Medium — Engineering Growth Framework
- Multiple skill dimensions, "varied paths to seniority"
- Interactive Snowflake UI visualization
- URL: https://docs.google.com/spreadsheets/d/1EO-Dbsayn8Nz9Ii3MKcwRbt-EIJ2MjQdpoyhh0tBdZk/

### Intercom — PM/Design Career Ladders
- PM dimensions: Insight Driven / Strategy / Execution / Driving Outcomes / Leadership Behaviors
- Separate IC and management ladders, PDF format

### 8th Light — Career Grid
- 2-axis model: technical ability x organisational impact
- Grid positioning over linear ladder
- Accommodates "born ICs" and management-track folks
