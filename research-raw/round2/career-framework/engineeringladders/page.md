# engineeringladders.com — Open framework (Jorge Fioranelli)

Source: http://www.engineeringladders.com/
Repo: https://github.com/jorgef/engineeringladders

## Five dimensions (radar chart)
1. **Technology** — adopting -> creating new technologies
2. **System** — enhancing features -> leading technical excellence
3. **People** — learning -> managing teams
4. **Process** — following -> defining
5. **Influence** — subsystem -> tech community

## Four career paths
1. Developer (D1-D7)
2. Tech Lead (TL1-TL7)
3. Technical Program Manager
4. Engineering Manager (EM5-EM7)

## Levels
- 1-7 across all paths
- Level 4+ = "senior"
- "Every level includes the previous one(s)" — cumulative

## Visualization
- **Radar/spider chart** per person showing position on each of 5 dimensions
- Visual gap analysis built into the framework itself
- Comparison page for IC vs manager roles

## Philosophy
- Conversation guide, not checklist
- Customize per organization
- "Performing at next level consistently for several months" before formalizing promotion
