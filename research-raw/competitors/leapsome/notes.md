## Performance
- Modular: Reviews, Goals/OKRs, Engagement Surveys, Competency Frameworks, Instant Feedback — each is a "block" that plugs in.
- Review types: 360°, self, peer, manager, project-based, leadership, external.
- Custom rules and workflows; automated reminders and notifications.
- Anonymous peer feedback with granular anonymity settings per question.
- AI Review Assistant: voice or text; guided prompts, reframing suggestions, evidence-based drafts.
- Heatmap dashboards aggregating multi-cycle performance data.
- Calibration tools framed as "fairness layer" — bias mitigation.

## Compensation
- Pay cycles tie to performance review ratings (rating → recommendation rule).
- Built-in templates + custom rules to model org's comp philosophy.
- Manager AI Copilot for promotion/pay conversations.
- Shared dashboards expose trends by team, gender, seniority — pay-equity built into the standard view.
- Approved changes push to payroll via HRIS, no manual data entry.
- 75+ HRIS integrations.

## Signature UX
- "Modular blocks" philosophy — each module is independently configurable but rated/composed across.
- AI assistant is *embedded* in the writing surface, not a separate page.
