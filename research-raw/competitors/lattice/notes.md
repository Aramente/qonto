## Performance reviews
- Customizable templates with downward review options, submission sequences, visibility settings.
- Flexible cadences: annual, quarterly, project-based, automated.
- Progress dashboard with completion % per status ("20% completed, 40% still receiving, 40% not started").
- Manager + self review: contextual integration of current AND next-level job descriptions, real-time performance summaries, suggested actions.
- AI-powered peer feedback summaries that synthesize input from colleagues.
- AI-generated growth-area suggestions in IDPs based on last 6 months of feedback.
- Custom feedback templates surfaced inline in the feedback request flow.

## Calibration UX (signature)
- Box view: drag-and-drop avatars on a 2-axis grid (axes = chosen calibration questions, picked via dropdowns).
- Calibration table sits next to box; moving avatars updates the table live.
- AI review-packet summaries surface inside each calibration session so reviewers can scan a person in seconds.
- Bell-curve view to show rating distribution across managers; surfaces "this manager trends high/low vs peers."
- Mid-cycle calibration progress monitoring.
- 2025 update: comments on rating changes; granular visibility controls (different stakeholders see different views).
- Gap (per Confirm): no behavioral evidence layer, no ONA, no automated bias detection beyond high/low surfacing.

## Talent reviews
- 9-box grid plotting performance vs potential.
- Succession planning module.
- All evaluation, goals, engagement data fused in one place.
