## Features
- "Lancement de campagne en 3 clics" — explicit positioning.
- Entretiens annuels, professionnels, 360°, check-ins continus, 1:1s.
- Matrix goals management; gestion d'objectifs matricielle.
- "Smart promotion management" — workflow promo intégré.
- Templates personnalisables (questions, types).
- Suivi temps réel de l'avancement campagne.
- Reports + dashboards personnalisables.
- Reconnaissance peer-to-peer.
- Intègre Lucca, BambooHR.

## Signature UX
- Interface "simple, épurée, conviviale" — positionnement délibéré contre les SIRH lourds.
- Onboarding inline (tutoriels intégrés) — prise en main en quelques minutes.
- Étapes d'entretien claires et expliquées dans le help center (collaborateur → manager → validation → signature → restitution).
- 86% G2 satisfaction.

## Position vs Lucca
- Javelo = "performance pure-play" (entretiens, OKR, feedback) → ressemble à Lattice version FR.
- Lucca = SIRH complet où la perf est un module.
- Beaucoup de scale-ups FR utilisent les deux côte à côte (Lucca pour la paie/temps, Javelo pour les entretiens).
